RailGPT – Technical Architecture

Technology Stack Breakdown:

  • React.js: Component-driven responsive interface, custom hook states, Axios services.
  • FastAPI: Asynchronous high-performance REST APIs, Python Pydantic validation, CORSMiddleware.
  • SQLite: Local data storage with efficient indexing for train schedules and login credentials.
  • Gemini AI: LLM prompt architecture to process natural language questions and map to query parameters.
  • Material UI: Visual components, customized theme engine.

Architecture Details:

The application is designed using a decoupled Client-Server architecture. The client handles view orchestration and renders responses dynamically. The FastAPI backend contains services that interact with the SQLite DB for static train lookups and call the Gemini API recursively to process open-ended user questions into train scheduling coordinates, providing a seamless smart assistant experience.
